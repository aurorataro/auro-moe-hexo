# 第0天/12月2-3日

## 天府机场——成都民宿

- 终点：[四川省成都市锦江区恒大望江华府5号门](https://surl.amap.com/3hJrDex7F137)

### 1. 公共交通 (1小时17分 17元)

{% note secondary %}

🚶步行至**天府国际机场(T2)**，乘坐***天府国际机场公交专线1️⃣号线<春熙路站方向>***

💲（1站 49分钟 15元）

🚌乘坐公交专线，到**万科路口**下车

🚶步行至**成渝立交(C口)**，乘坐***2️⃣号线地铁<犀浦方向>***

💲（2站 5分钟 2元）

🚇️乘坐2️⃣号线地铁，到**塔子山公园**下车，出口是*通往天廊T66*

🚶步行至终点

{% endnote %}

### 2. 打车

{% note secondary %}

🚕前往**T1航站楼-P1停车场L1层-网约车上客区**直接打车至目的地，约47分钟，白天价格约为75+39=114元，夜晚价格约为95+39=134元，其中39元为高速费。

{% endnote %}

# 第1天/12月3日

## 成都民宿——金沙遗址博物馆

终点：[金沙遗址博物馆](https://surl.amap.com/3mrtOoCxV6JJ)

{% note secondary %}

全程46分钟 ￥5 步行1.3KM

🚶步行至**塔子山公园**，乘坐***2️⃣号线地铁<犀浦方向>***

🚇️乘坐2️⃣号线地铁，到**一品天下**下车，站内换乘至***7️⃣号线地铁<金沙博物馆方向>***

🚇️乘坐7️⃣号线地铁，到**金沙博物馆**下车，出口为*C口*

🚶步行至终点

{% endnote %}

## 金沙遗址博物馆——海德林咖啡餐厅

终点：[海德林咖啡餐厅](https://surl.amap.com/59BGUoy12doH)

{% note secondary %}

全程47分钟 ￥5 步行1.1KM

🚶步行至**金沙博物馆(C口)*，乘坐***7️⃣号线外环地铁<文化宫方向>***

🚇️乘坐7️⃣号线外环地铁，到**火车南站**下车，站内换乘至***1️⃣8️⃣号线地铁<天府机场北方向>***

🚇️乘坐1️⃣8️⃣号线地铁，到**孵化园**下车，出口为*E2口*

🚶步行至终点

{% endnote %}

## 海德林咖啡餐厅——成都民宿

{% note secondary %}

全程48分钟 ￥4 步行1KM

🚶步行至**心岛(C口)*，乘坐***9️⃣号线地铁<金融城东方向>***

🚇️乘坐9️⃣号线地铁，到**金融城东**下车，站内换乘至***6️⃣号线地铁<望丛祠方向>***

🚇️乘坐6️⃣号线地铁，到**牛王庙**下车，站内换乘至***2️⃣号线地铁<龙泉驿方向>***

🚇️乘坐2️⃣号线地铁，到**塔子山公园**下车，出口为*通往天廊T66*

{% endnote %}
